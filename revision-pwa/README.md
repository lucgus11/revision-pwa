# Révision Masquée (PWA)
Synthèses de cours avec mots masqués. TypeScript + Vite + IndexedDB (`idb`) + `vite-plugin-pwa`.

    npm install
    npm run dev      # développement
    npm run build    # production (dossier dist/)

Masquer un mot : sélection + bouton "Masquer" / Ctrl+M, ou taper `[[mot]]` ou `~mot~`.
Déploiement : importer le dépôt dans Vercel (preset Vite détecté automatiquement).
